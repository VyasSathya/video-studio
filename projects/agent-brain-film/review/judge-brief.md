# Brief (what the video was supposed to be)

A product-launch film of about 20 seconds for agent-brain, a free open-source command-line tool: one shared memory
for coding agents (Claude Code and Codex) kept in a plain folder. Agents route a folder to its project, read the
current handoffs, and save handoffs that cite a path, a line number and the exact quote in the repo; the tool flags
evidence_changed when the cited file changes afterwards. Python standard library only: no model calls, no network,
no service. The benchmark is a launch film by Apple, Linear, Raycast or Arc: it should look made by a design studio,
not like a screen recording or a template.

- The only product UI is the tool's real output: commands and what they printed, and real files from its example
  repo, typeset on its own colours (blue for what you run, orange for evidence). Nothing else may be presented as
  product output.
- The cards sit on a lit background with depth; the camera pushes in on the line that proves each point.
- Story, one short sentence per shot: your agents forget; it remembers; it knows your project; every
  note cites the line; it refuses to overwrite silently; it notices when the cited file changes; plain files, no
  service.
- Cuts on the beat, 1 to 3 s each. End card: the name agent-brain, one line, github.com/VyasSathya/agent-brain.
- Music only, no voiceover. Faceless.
- Two formats: 16:9 (1920x1080) and a 9:16 recomposition (1080x1920) for phones.
