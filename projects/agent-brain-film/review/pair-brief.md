Two short product-launch films, each shown as two frame strips: the 16:9 version and the 9:16 phone version, one
frame every 0.5 s with the time on each tile. Each film is about 20 seconds, faceless, music only, no voiceover,
for a free open-source developer tool, and each may show only that tool's own real interface or output. One film is
for Talkover (hands-free, two-way voice for Claude Code: a small floating panel with a coloured orb and a caption
line). The other is for agent-brain (a shared memory for coding agents in a plain folder: a command-line tool whose
real terminal output and files are its interface). The benchmark for both is a launch film by Apple, Linear, Raycast
or Arc. The rubric in this folder lists what a good launch film does; use it as criteria, not as a checklist to
score.
